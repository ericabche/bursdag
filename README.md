# Bursdagsside 🎉

Interaktiv bursdagsside laget med HTML, CSS og JavaScript.

1. **Start:** play-knapp som viser en video i fullskjerm
2. **Mood check:** de dårlige knappene knuses, bare smilefjeset kan trykkes
3. **Neste del:** kommer

## Kom i gang

Legg videoen i `video/` med navnet `bursdag.mp4`, og åpne `index.html` med *Live Server* i VS Code (eller `npx serve`).

## Mappestruktur

```
├── index.html      # Alle skjermene
├── css/style.css   # Utseende og animasjoner
├── js/
│   ├── main.js     # Starter siden og bytter skjerm
│   ├── video.js    # Play-knapp og video
│   └── mood.js     # Mood check og knusing
├── video/          # Bursdagsvideoen
├── bilder/         # Bilder, f.eks. det som faller ned
└── lyd/            # Lydeffekter
```
